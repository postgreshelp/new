analyze threshold = autovacuum_analyze_threshold + autovacuum_analyze_scale_factor * number of tuples
vacuum threshold = autovacuum_vacuum_threshold + autovacuum_vacuum_scale_factor * number of tuples

if a table has 1000 records, the table is a candidate for analyze    if it has 50+0.1*1000 records i.e., 150 changed.
if a table has 1000 records, the table is a candidate for autovacuum if it has 50+0.2*1000 records i.e., 250 changed.

For business critical large table, change the scale factors. 
or else, disable autovacuum and schedule manual vacuum
Also schedule manual vacuum at non-business hours
